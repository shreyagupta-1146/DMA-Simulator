# DMA Controller Simulator

A real-time simulation of DMA (Direct Memory Access) controllers for embedded systems, demonstrating the performance difference between CPU-only and DMA-assisted data transfers.

## 🎯 Project Highlights

- **Real-time Visualization**: Task Manager-style UI with live animated graphs
- **OS Simulation**: Switch between Windows, Linux, macOS, and Android profiles
- **File Transfer Demo**: Simulate transfers for text, images, documents, videos
- **Performance Metrics**: CPU cycles, utilization %, throughput, efficiency
- **Academic Rigor**: Perfect for 2nd-year B.Tech embedded systems project

## 🚀 Quick Start

### Prerequisites
- Python 3.8+
- pip package manager

### Installation & Run

```bash
# Clone the repository (or create the project structure manually)
git clone <repo-url>
cd dma_simulator

# Install dependencies
pip install -r requirements.txt

# Start the server (Option 1: Quick start)
python run.py

# OR (Option 2: Manual start)
cd backend
python app.py
